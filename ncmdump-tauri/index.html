ncmdump-tauri

Login to NetEase Cloud Music in the embedded webview

This example now supports both NetEase and Bilibili. It uses the same pattern as `ytdl-audio`: navigate the Tauri webview to the site, finish login there, then extract cookies from that webview into the Rust session store.

Flow

  1. Choose NetEase or Bilibili.
  2. Click the open button. The main Tauri webview navigates to music.163.com.
  3. Finish login inside that same webview.
  4. Click the capture button. The app reads the webview cookie store and persists the matching backend session.
